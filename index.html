    ❓ Madad / Help
    • Ye app karta kya hai? Ek badi novel file (jaise 500 chapters ka EPUB) ko chhoti files me baant deta hai — jaise har file me 10 chapters.
    • Chapters galat mil rahe hain? Step 2 me upar "Try karein" buttons dabayein, ya Advanced mode on karke "Chapter detection settings" kholein.
    • Koi chapter nahi mila? Shayad aapki file me headings sirf numbers hain ("1.", "002") — "Numbers wale headings" button dabayein.
    • Kuch chapters chhodne hain? Step 2 ki list me unka ✓ hata dein.
    • Kindle pe padhna hai? EPUB format chunein, phir Amazon ki "Send to Kindle" service se bhejein.
    • Meri file kahin upload hoti hai? Nahi. Sab kuch aapke browser ke andar hota hai, internet band karke bhi chalega.
    • Shortcut: Ctrl+Enter = ZIP download.
